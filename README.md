# Buscajuegos: base de datos de juegos de mesa para la intervención en Terapia Ocupacional

Base de datos de 62 juegos de mesa analizados desde la Terapia Ocupacional: para cada juego, edad, duración y jugadores, y la importancia (0 a 3) de 53 componentes motores, sensorio-perceptivos, cognitivos, psicosociales y emocionales.

Versión web: https://centrotangram.com/buscador.html

## Contenido

- `datos/buscajuegos.csv`: una fila por juego. Columnas generales (título, edad recomendada, duración, jugadores, descripción, enlace de compra y vídeo explicativo) y una columna por componente, con el formato `Grupo: componente`.

## Escala de los componentes

| Valor | Significado |
|---|---|
| 3 | Fundamental |
| 2 | Importante |
| 1 | Presente |
| 0 o vacío | Ausente o no necesario |

Grupos: componentes motores (12), sensorio-perceptivos (13), cognitivos (19), psicosociales (5) y emocionales (4).

## Cómo se ha hecho

Cada juego lo ha analizado un terapeuta ocupacional a partir de su uso en sesión. Es una valoración clínica, no una medida estandarizada: sirve para orientar la elección del juego, no para sustituir el razonamiento clínico.
